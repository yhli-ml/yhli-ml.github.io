# yhli-ml.github.io

Personal website of Yuhang Li, served at <https://yhli-ml.github.io>.

Plain static HTML/CSS/JS, with no build step. To preview locally:

```sh
python3 -m http.server 8123
```

- Home page text lives in [`home.md`](home.md).
- Reading notes live in [`reading.md`](reading.md); add a `## Title` block to post a new one.
- How to edit everything else: see [EDITING.md](EDITING.md) (in Chinese).
